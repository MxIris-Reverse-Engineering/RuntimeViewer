# v3.0.0-beta.5

## New

- `runtime-viewer-cli` now ships inside the app at `RuntimeViewer.app/Contents/Applications/runtime-viewer-cli`; it works without the app open, and every command supports `--json`.
- Images opened on "My Mac" now load in a separate service, so a crashing image no longer takes down the app.
- A class listed under both Swift and Objective-C now links its two entries; right-click either one to jump to the other.
- **Navigate → Reveal in Sidebar Navigator** (⇧⌘J) selects the current object in the sidebar.
- **Settings → Editor** lets you choose which installed Xcode the source editor uses.
- New app icon that adapts to dark, tinted and Liquid Glass appearances; beta builds carry a BETA badge.
- New **Infers ObjC Overrides From Selector Names** option in Generation Options, off by default.

## Improved

- Icons in the sidebar, Open Quickly and the Inspector now have tooltips.
- Private Swift types show their discriminator in the sidebar, so same-named types can be told apart.
- Batch export now shows indexing progress instead of staying on **Queued**.
- Opening an image while others index in the background is faster.
- While an interface loads, the content pane shows a spinner instead of the previous object's text.
- On macOS 27, the sidebar and Inspector tab switchers use the system tab style.

## Fixed

- Fixed the Mac Catalyst engine loading forever.
- Fixed wrong addresses for property accessors whose name matches a class method.
- RuntimeViewer's own injected code no longer appears in a target's image list.
- The Relationships tab now lists Swift subclasses of Objective-C classes and conformers of nested Swift protocols.
- Fixed overlapping rows after filtering or expanding far down a long list.
- Fixed grey row highlights, missing context menus, drag selection and a flash when navigating the sidebar on macOS 27.
- The source editor's minimap shows its hover labels again, and the editor works with Xcode 27.
