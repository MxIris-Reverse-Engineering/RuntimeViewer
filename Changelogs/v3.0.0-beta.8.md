# v3.0.0-beta.8

## New

- The Find navigator's new **Call Hierarchy**, **Callees** and **Type References** modes show who calls a method, what it calls and which functions use a type.
- Start a search from **Edit → Find** (**Find Call Hierarchy** is ⌃⇧⌘H) or by right-clicking a name in the interface.
- The Inspector's new **References** tab shows the callers, callees and type references of the member at the insertion point.
- Cross references read the arm64 and arm64e code of indexed images, in the background unless **Settings → Search → Keep Cross References Ready** is off.
- The sidebar's filter fields take Xcode's navigator tokens — `NS*`, `*View`, `!Private`, and `*` and `?` as wildcards — and keep recent filters.
- The Inspector's **Hierarchy** tab lists a class's superclasses as clickable rows, and the protocols a protocol refines as an outline.

## Improved

- Find keeps the searchable interfaces of system frameworks on disk and reads them back on the next launch instead of rebuilding them.
- **Settings → Indexing → Derived Data** shows how much disk they take and deletes them.

## Fixed

- Fixed an issue where the sidebar could not be resized right after launch.
- Choosing another **Filter Mode** now refilters the sidebar's object list right away.
- A window whose engine restarts now starts over instead of showing a stale image.
- Long result titles in the Find navigator end in an ellipsis instead of being cut off.
