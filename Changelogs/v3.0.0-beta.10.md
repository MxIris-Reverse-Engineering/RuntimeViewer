# v3.0.0-beta.10

After updating, RuntimeViewer reinstalls its helper service once and asks you to restart it.

## New

- **File → Open…** (⌘O) opens Mach-O files, bundles, folders and dyld shared caches from disk, each in its own window.
- **Settings → Files** registers the dyld shared caches that files from other platforms, such as iOS, depend on.
- C++ classes and namespaces, recovered from RTTI, vtables and symbols, are listed beside Objective-C and Swift objects and print as headers.
- Export can write C++ headers too.
- Split the content area into editor panes with **File → New Editor Pane On Right** or **Below**; each pane has its own tabs and history.
- Each editor pane has a jump bar for switching images and objects without moving the sidebar.
- An empty tab shows a start page with an Open Quickly field and your recent images or objects.
- **Open Quickly** (⇧⌘O) now searches every image and indexed object on the engine.
- A welcome window appears at launch and when you click the Dock icon with no windows open (**Settings → General → Show Welcome Window at Launch**).
- **Open Generated Interface** shows an Objective-C class, category or protocol as Swift imports it.
- `@Observable` classes print as written in source, with their macros expandable in place or through **Expand Macros** in Generation Options.
- **Break Long Types**, in Generation Options, wraps long Swift types such as SwiftUI's `Body` over several lines.
- **Show Naming Word Cloud** draws the most common words in an image's type, property and method names, and exports them as PNG, CSV or JSON.
- The toolbar shows background progress and picks the runtime source as Xcode 26 or 27 does (**Settings → General → Activity Style**).
- The source editor remembers where you were in each object, highlights other uses of a clicked name and Find matches, and gains **Editor → Code Folding**.
- Context menus everywhere gain Copy Name, Open in Next Editor Pane, Show in Finder and more.
- New keyboard commands: **Navigate → Go Back** (⌃⌘←) and **Go Forward** (⌃⌘→), ⌫ to delete a bookmark, ⌘C to copy a sidebar row's name.
- `runtime-viewer-cli` and the MCP server gain callers, callees, type references and address symbolication.
- **iOS and visionOS:** the sidebar's gear button opens Settings for appearance, theme and transformer options.
- **iOS and visionOS:** open Mach-O files, folders and dyld shared caches from disk, also from the Files app.
- **iOS:** iPad supports multiple windows.

## Improved

- The source editor is now built into RuntimeViewer on Apple silicon Macs, so Xcode no longer needs to be installed.
- **Load Frameworks…** on My Mac loads into a separate window and process, and explains a failed load.
- Attached processes reuse My Mac's indexes of system images, so they open faster and burden the target less.
- My Mac can open UIKitCore and other images built only for Mac Catalyst.
- Filter Scope is remembered per engine and image, across windows and launches.
- Images show Xcode's icons and colours for their kind throughout the app.
- On macOS 26 and later the content scrolls under the toolbar and tab bar with a blur, as in Xcode.
- ⌥-click opens an object in the next editor pane, ⇧⌥-click in a new tab, and an object already open is switched to instead.
- The interface no longer shows a blinking caret; **Settings → Editor → Insertion Point** brings it back.
- RuntimeViewer's download is smaller.

## Fixed

- **Print Exported Declarations Only** now also leaves out private `@objc` protocols and the categories adopting only them.
- Removing a bookmark from a filtered list no longer removes a different one.
- Closing the export sheet now stops the export.
- The Theme editor no longer loses the last change when it closes.
- Revealing an object in the sidebar no longer leaves its row hidden under the section header or the filter bar.
