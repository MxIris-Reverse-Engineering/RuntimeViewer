# v3.0.0-beta.1

First public preview of the **3.0** line, and the largest single step since 2.0.
The content pane can now be driven by Xcode's own source editor, injection
reaches iOS Simulator processes, remote mirroring stops inventing ghost devices,
and the sidebar's filtering and Open Quickly paths were rebuilt to stop doing
their work on the main thread.

This is a `beta` build — only clients that opted in via
**Settings → Updates → Include pre-release versions** receive it.

---

## Xcode's Source Editor as the content view

The content pane can now be backed by the editor Xcode itself uses, which brings
code folding, sticky headers, a find bar, scope guides and ⌘-hover underlining
without any of them being implemented here. On a 5 MB interface its worst frame
is 9.43 ms against TextKit 2's 25.08 ms.

- **Opt-in**, under **Settings → Editor**. Every failure path — no Xcode
  installed, an arm64e build, a missing bundle — falls back to the existing
  TextKit 2 view, because both are driven by the same view model.
- The app links none of Xcode's frameworks. A link-time dependency on
  frameworks that live inside Xcode would abort in dyld before `main` on a
  machine without it, so the only code referencing those symbols sits in a
  loadable bundle that is `dlopen`ed on demand.
- **Jump to Definition** and ⌘-click work in the new view, resolved against the
  same link attributes the TextKit path uses.
- Syntax colouring comes from the parse rather than being painted over it, and
  the current-line highlight is now a theme slot like every other colour.
- Margins, overlays, invisibles and mark separators are exposed as settings.

## Injecting iOS Simulator processes

Attaching to a simulator process used to kill it. A macOS process and an iOS
Simulator process on the same Mac share a cputype and differ only in
`LC_BUILD_VERSION`, so nothing about the target's architecture revealed that it
was being handed the macOS payload; dyld refused the slice, the daemon's remap
fallback projected it anyway, and the kernel killed the process on page-in.

- The target's platform is now read from its executable's `LC_BUILD_VERSION`,
  not guessed from its path.
- The iOS Simulator slice ships as a sibling bundle and is selected by platform.
  A target with no slice to offer — a tvOS Simulator process, say — gets an
  explicit error instead of the nearest slice and dyld's verdict.
- A simulator attach is confirmed by device *and* pid, since pids are not unique
  across booted simulators.

## Remote mirroring and Bonjour

- **Ghost devices are gone.** A browse result that arrived before its TXT record
  made self-filtering, grouping and loop detection all fall back to the service
  name, so a Mac discovered itself and listed it as a stranger. Results are now
  held until their identity arrives, and the advertised service name is
  recognised as a local identity.
- Every advertising process carries its own identity, so two engines on one host
  no longer collide.
- The advertised name is the resolved device name and is stable across launches.
- The Catalyst helper no longer registers itself in the injected-endpoint
  registry, where a reconnect scan would treat it as an injection target and
  displace the real engine.

## Persistence identity

Bookmarks, sidebar expansion state and the sidebar's autosave key were each
deriving their own key, one of them from a display name and one including a pid.
All three now key on a stable `RuntimeBookmarkScope`, so bookmarks survive a
process restart instead of disappearing without a word.

## Performance

Roughly twenty changes, concentrated in three places:

- **Open Quickly** materializes rows lazily on match, shares one haystack build
  per pass, ranks before capping at the top 500, and checks the generation
  before a pass starts. Previously every row of a 14 k-object image was built up
  front.
- **Sidebar filtering** moved off the main thread, and root image-tree filtering
  with it.
- **Interfaces are cached** per navigation, keyed by the object the interface
  names, so revisits skip the engine entirely; theme changes no longer re-fetch
  the text.
- Per-image index state is released instead of being pinned for the engine's
  lifetime, and one-shot symbols demangle transiently.

## Under the hood

- **Navigation runs on AppKitPlus** instead of Apple's private `UXKit`.
- **Settings** are stored through UIFoundation's shared settings store, with the
  load and the final save owned explicitly rather than happening as a side
  effect.
- **The main menu is built in code**; `MainMenu.xib` is gone.
- Release builds refuse to publish without the iOS Simulator payload rather than
  shipping an app whose simulator injection silently fails.

## Upgrade notes

The privileged helper's protocol version moves to **1.6.0**, so the first launch
after updating asks for administrator authorization to replace it. The daemon's
connection and networking layers changed substantially in this release; without
the replacement an installed client would keep running the old helper.
