# v3.0.0-beta.9

After updating, RuntimeViewer reinstalls its helper service once and asks you to restart it.

## New

- With **Use Xcode's Source Editor** on, generated comments show as tags, and field and enum case layouts collapse (**Settings → Editor → Comment Tags**).
- **Print Exported Declarations Only**, in Generation Options for Swift and Objective-C, leaves out what an image does not export.
- The sidebar marks what an image does not export, and a **Not Exported** row in Filter Scope filters it.
- Objective-C protocols defined in Swift carry a Swift badge, and a **Defined in Swift** row in Filter Scope filters them.
- The Swift list shows `@objc` protocols declared in Swift, and Swift classes list the Objective-C protocols they adopt.
- The Report navigator shows the memory searchable interfaces and cross references take, and frees it.

## Improved

- RuntimeViewer uses much less memory: Find and cross references keep only a limited amount resident (**Settings → Search**).

## Fixed

- Fixed memory that kept growing while connected to a remote device or an injected process.
