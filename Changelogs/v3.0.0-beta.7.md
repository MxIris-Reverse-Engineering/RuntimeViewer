# v3.0.0-beta.7

## New

- **Find navigator**: search the interfaces of every indexed image for text, find types by name together with their ancestors, descendants or conforming types, or find properties, methods and other members. Narrow the scope to the current image, the images in the results, or images you pick; a result opens its type at the matching line. Text searches can insert patterns such as Digits or Email Address, and recent queries are kept for each source. Open it with **Edit → Find → Find in Indexed Images…** (⇧⌘F).
- **Report navigator** (**View → Show Report Navigator**, ⌘9): background indexing and the building of searchable interfaces, running and finished, now live in a sidebar tab with a filter bar, in place of the toolbar's Background Indexing button. Every window on the same engine shows the same Report.
- Private Swift types are listed by name with a **Private** tag; click it to see the full discriminator and, when it can be worked out, the source file. Types declared inside a function carry a **Local** tag.
- Each **Always Index** entry can be limited to particular engines: My Mac, Mac Catalyst, an attached process or a device.
- **Filter Scope** can narrow the sidebar by every object property, including Objective-C classes implemented in Swift, bridged Swift classes and local types.
- Batch export picks images from a tree with tri-state checkboxes; its search supports regular expressions, case sensitivity and matching full paths.
- **Jailbroken iOS devices**: with RuntimeViewer's jailbroken iOS build running on the device, Attach to Process lists the device's processes, with their app icons, and injects into them. The jailbroken build is made with `BuildJailbrokenIPAScript.sh` and is not among this release's downloads.
- A Claude Code and Codex plugin in `AgentPlugins/runtime-viewer` teaches coding agents to use `runtime-viewer-cli`.

## Improved

- The **My Mac (Mac Catalyst)** engine runs in a service embedded in the app: it starts on demand and reconnects by itself if it crashes.
- On macOS 26 and later the sidebar is laid out like Xcode's navigator: the lists run under the tab switcher and the filter bar, with the scroll edge effect.
- The sidebar's filter bars and search fields use the same controls as Xcode's.
- Background indexing and searchable-interface builds keep their speed while RuntimeViewer is in the background.
- The specialization type picker lists the subclasses in images indexed after the type was first opened.

## Fixed

- Opening a second window on an engine no longer adds batches of 0 images to the indexing list, or reloads the engine once per window for each batch; closing that window, or moving it to another engine, no longer cancels the first window's indexing.
- Detaching from an injected process, or quitting it, while a reply is still on its way no longer crashes RuntimeViewer or the process.
- The Relationships tab lists the subclasses of a generic class bound to type arguments.
- A long window title no longer pushes the toolbar's source picker and buttons into the overflow menu.
- The source editor shows its scroll bars as System Settings asks, instead of always hiding them.
