# Draft - ⌥-点击开到另一栏，已打开的对象直接切过去

- **状态**: In Progress
- **创建日期**: 2026-11-14
- **最后更新**: 2026-11-14
- **所属愿景**: 无
- **实现分支 / PR**: `feature/option-click-next-editor-pane`

## 摘要

[0076](0076-editor-panes.md) 照 Xcode 27.2 的默认值定了修饰键：⌥-点击在焦点栏开新标签，⇧⌥-点击开到下一栏。改为 ⌥-点击开到下一栏（只有一栏时在旁边新开一栏），⇧⌥-点击开新标签，即 Xcode 把可选导航设成「Uses Separate Editor」时的做法：分栏比标签更常用，就让它占单个修饰键。另外，开新标签和开到下一栏之前先看这个对象是不是已经开着：已经有标签在显示它，就切到那个标签、焦点移到它所在的栏，不再开第二份。

## 方案

**修饰键对调。** 所有入口都经 `SelectionRouteDestination+ModifierFlags.swift` 把修饰键换算成去处，只改这一处：

| 入口 | 普通 | 下一栏 | 新标签 |
|------|------|--------|--------|
| 列表里的点击（侧栏、Find 结果、Inspector 各列表、路径栏菜单、Navigate ▸ Generated Interface） | 点击 | ⌥ | ⇧⌥ |
| 内容区的类型链接 | ⌘ | ⌥⌘ | ⇧⌥⌘、⇧⌘ |

⇧⌘-点击仍开新标签，是本应用一贯的写法，与 Safari 相同。右键菜单的 Open in New Tab / Open in Next Editor Pane 不变。

**已打开就切过去。** 去处是新标签或下一栏时，路由层（`DocumentState` 处理 `.open` 与 `.openImage` 的地方）先问 `EditorArea.tabID(showing:)`：哪个标签此刻正显示这一条目。找到就由 `EditorArea.bringForward(_:showing:)` 把它设为所在栏的当前标签、把焦点移到那一栏，发出 `.switchTab`，与点那个标签一样；带着要高亮的位置（Find 结果）时发出在焦点标签打开的 `.open`，照样高亮。找不到才照旧开新标签或下一栏。

- 只认标签当前显示的条目，历史里往前或往后的不算；条目按身份比较，同一个类的头文件与 Generated Interface 是两个条目，镜像页按路径比较。
- 先找焦点栏，再按从左到右、从上到下找其他栏；每一栏先看当前标签，再按顺序看其他标签。
- 切过去不改那个标签的历史，前进记录保留；只有对象带着新内容时（`hasSameContent(as:)` 不成立）让当前条目换成新的那份，与 `NavigationHistory.record(_:)` 回到同一步时的做法一致。

**没问就定下的假设。**

- 普通点击（焦点标签）不查已打开的标签，照旧在当前标签里原地打开，在侧栏里连续浏览时焦点不会在标签和栏之间跳。
- 已经分成几栏时，⌥-点击沿用 `.nextEditorPane` 的做法开到焦点栏的下一栏，不再新加一栏。
- 已落地提案（0076、0084、0086、0092）正文里的修饰键说明保留原样，作为当时的记录；现状以本提案、README、术语表与路径栏功能地图为准。

**落地步骤。**

1. 对调修饰键，改换算函数、它的测试与各处说明修饰键的注释。
2. `EditorArea` 加 `tabID(showing:)` 与 `bringForward(_:showing:)`，`NavigationHistory` 加让当前条目换成新内容的方法，路由层接上，补路由测试。
3. 更新 README、术语表、路径栏功能地图与提案索引。

| 2026-11-14 | 「已打开就切过去」只管新标签与下一栏，普通点击照旧 | 用户选定；普通点击是侧栏浏览的主路径，跳到别的标签或栏会打断浏览 |
| 2026-11-14 | 判断放在 `EditorArea`，由路由层调用；切过去时发出 `.switchTab`，带高亮时发出在焦点标签打开的 `.open` | 编辑区的唯一订阅者照常处理这两种路由：前者不重建已经显示着的内容，后者照样高亮；`EditorArea.open` 保持「一定新开」的含义 |
| 2026-11-14 | 四条测试改为先让当前标签显示别的对象，再在新标签打开 | 侧栏、右键命令、Inspector 与 Find 的这四条测试在新标签里打开的正是当前标签显示的对象，按新规则会切回原标签；改的是前置状态，「开新标签会多一个标签」的原意不变 |
