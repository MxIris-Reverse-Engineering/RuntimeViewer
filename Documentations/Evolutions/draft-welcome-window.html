摘要

macOS App 接入 UIFoundation 现成的 Xcode 风格欢迎窗口（WelcomePanelController，.xcode26 样式）。启动时、以及没有文档窗口时点 Dock 图标，弹出欢迎窗口，不再自动新开一个 My Mac 窗口：左侧是 App 图标、名字、版本和两个动作（New Window on My Mac、Open File…），右侧是最近打开的文件（与 File › Open Recent 同一份），双击即打开。任何文档窗口一出现，欢迎窗口就自己关掉。

Window 菜单加 Welcome to RuntimeViewer（⇧⌘1），设置 › 通用 › Windows 加「Show Welcome Window at Launch」开关（默认开），关掉即回到现在的行为。上游 UIFoundation 先给 WelcomePanelController.Configuration 加 projectListPlaceholderText，让空列表能显示「No Recent Files」，发 0.50.0 后 RuntimeViewer 打开 WelcomePanel trait、把下限抬到 0.50.0。

实线：调用或持有；虚线：读设置。WelcomeController 持有 UIFoundation 的面板，决策交给 AppCore 的 WelcomeWindowPolicy。

AppKit 问「开不开未命名文档」时设置多半还没读完：先回 false 并记下请求，读完设置再决定；这时已有文档窗口就什么都不做。方案不依赖这两个回调的先后。

详细设计

UIFoundation：projectListPlaceholderText 
public var projectListPlaceholderText: String?   // nil shows "No Recent Projects"

public init(
    style: Style = .xcode14,
    // …existing parameters, unchanged…
    tertiaryAction: Action? = nil,
    projectListPlaceholderText: String? = nil,
    checkShowOnLaunch: Bool = true
)

命名沿用同一结构里的 welcomeLabelText / versionLabelText；参数带默认值，现有调用点源码兼容。只加文字，不加字体与颜色。

设置：showsWelcomeWindowAtLaunch 
/// Whether launching the app, and clicking its Dock icon with no window open, shows the Welcome
/// window instead of opening a new window on My Mac.
@Default(true)
public var showsWelcomeWindowAtLaunch: Bool

设置页 Windows 一节在「Quit After Closing Last Window」之前加 Toggle「Show Welcome Window at Launch」，说明文字改写为：欢迎窗口列出最近打开的文件，没有窗口时点 Dock 也会出现；关掉则开新的 My Mac 窗口。

WelcomeWindowPolicy（RuntimeViewerAppCore） 
public enum WelcomeWindowPolicy {
    public enum Decision: Equatable, Sendable {
        case showWelcomeWindow, openUntitledDocument, waitForSettings
    }
    public static func decisionForUntitledDocumentRequest(areSettingsLoaded: Bool, showsWelcomeWindow: Bool) -> Decision
    public static func decisionAfterSettingsLoaded(showsWelcomeWindow: Bool, hasDocumentWindow: Bool) -> Decision?
    public static func decisionForReopen(showsWelcomeWindow: Bool) -> Decision
}

不用 ViewModel：面板内容在构造时就定了，没有随时间变化的状态；会变的只有这几处决策，放在 AppCore 由测试驱动。

WelcomeController（App target）与接线
  • 懒创建 WelcomePanelController（.xcode26）：标题取 CFBundleDisplayName（Debug 版的 CFBundleName 是 RuntimeViewer-Debug-arm64e），空列表文字 No Recent Files；动作 New Window on My Mac（newDocument，SF Symbol plus.square，即 Xcode 的 Create New Project… 那个）与 Open File…（openDocument，SF Symbol folder）。
  • data source 用 recentDocumentURLs；双击（先排除 -1）调 openDocument(withContentsOf:display:)，交给 DocumentController 与 FileController，出错时由后者报。
  • shouldOpenUntitledDocument() 回答 applicationShouldOpenUntitledFile(_:)；没读完设置时记下请求、回 false。start() 注册主窗口观察，再等 waitUntilLoaded() 处理记下的请求。
  • 文档窗口（windowController?.document != nil）成为主窗口时关面板。不在 addDocument 里关：那时文档窗口还没上屏，开着「Quit After Closing Last Window」会让 App 退出。
  • SettingsLifecycleController 存下 load 的 Task，补 isLoaded 与 waitUntilLoaded()。
  • AppDelegate 三处一行转发；WindowLifecycleController 最后一支改调 showInsteadOfUntitledDocument()；「有没有文档窗口」的表达式两处共用一个小扩展。
  • Window 菜单在 Bring All to Front 之前插 Welcome to RuntimeViewer（⇧⌘1，同 Xcode 的 Welcome to Xcode）与分隔线。

调研

UIFoundation 一侧
  • main 与 0.49.0 是同一个提交，没有未发版的改动；0.50.0 只含这一项。
  • 组件在 Sources/UIFoundationAppKit/WelcomePanel/，trait WelcomePanel 默认关，0.20.0 起就有。
  • window 与 contentViewController 不可访问，位置与外框由组件管；列表是拉取式，showWindow 与窗口重新可见时重读。
  • .xcode26 没有「启动时显示」勾选框，只用公开 API，macOS 15 可用。
  • 缺口：空列表文字写死 No Recent Projects（WelcomePanel+ProjectsViewController.swift:54）。
  • 测试 18 个，要带 --traits WelcomePanel 才编进来。
RuntimeViewer 一侧
  • 没实现 applicationShouldOpenUntitledFile(_:)，AppKit 默认开未命名文档，放在 My Mac 上。
  • 窗口恢复在 applicationDidFinishLaunching 之前（2026-09-18 的 ResolvedIssue 有调用栈）；推测「开未命名文档」的询问也在那之前，未实测，方案不依赖它。
  • 设置在 applicationDidFinishLaunching 里异步读，询问时多半没读完。
  • Document 从不存盘，最近文档只有文件模式读过的文件；打开走 DocumentController → FileController。
  • 「Quit After Closing Last Window」默认关；开着时关掉唯一的窗口会退出 App。
  • Attach 与 Load Frameworks 是主窗口的路由，没有窗口就发不起来。
  • 锁文件：Debug / Distribution 钉 0.49.0，RuntimeViewer.xcworkspace 钉 0.47.0；⇧⌘1 未被占用。

替代方案

七条，均已否决
  • 启动照旧开 My Mac 窗口、欢迎窗口只从菜单打开：用户选了取代。
  • macOS 改同步读设置：改的是整个 App 读设置的时机，另一件事；这里只等这一处。
  • 在 RuntimeViewer 里自己写欢迎窗口：UIFoundation 已有实测复刻。
  • 照现状显示 No Recent Projects：用户选了先改上游。
  • 用 .xcode14 换来勾选框：外观与 App 其余界面不一致。
  • 在 addDocument / makeWindowControllers 里关欢迎窗口：文档窗口还没上屏，可能让 App 退出。
  • 给欢迎窗口配 ViewModel 与 coordinator：没有可变状态，决策放进 WelcomeWindowPolicy。

影响

  • 用户可见：启动与没窗口时点 Dock 弹欢迎窗口；要原来的窗口点 New Window on My Mac、按 ⌘N 或关掉开关。Window 菜单新增 ⇧⌘1。恢复窗口或经 Finder 打开文件时不出现欢迎窗口。
  • 可发现性：默认开，一启动就能看到。
  • 兼容：新设置键缺省为 true，不需要迁移；最近文档仍是系统的 Open Recent。
  • 平台：只涉及 macOS，下限不变（15）；iOS 只多一个不显示的设置字段。
  • 发布：无新权限，不影响公证与 Sparkle；UIFoundation 先发 0.50.0；发版说明写一句。

落地步骤

  1. UIFoundation：空列表文字可配，发 0.50.0——placeholderTextDefaultsToNoRecentProjects、placeholderTextComesFromConfiguration；会开窗口的测试放另一台机器跑。
  2. 打开 trait、抬下限——包与 App 都能编，./TuistScript.sh check 通过。
  3. 设置开关——showsWelcomeWindowAtLaunchDefaultsToTrue、legacyPayloadWithoutTheKeyShowsTheWelcomeWindow。
  4. 决策——untitledRequestBeforeSettingsLoadWaits、untitledRequestShowsWelcomeWindowWhenEnabled、untitledRequestOpensUntitledDocumentWhenDisabled、heldLaunchRequestDoesNothingOnceADocumentWindowIsUp、heldLaunchRequestFollowsTheLoadedSetting、reopenFollowsTheSetting。
  5. App 接线——App 构建通过；启动、开关、双击最近文件、两个动作、Dock、⇧⌘1、「Quit After Closing Last Window」开着时不退出，由用户目视验收。
  6. 文档——App 层 AGENTS.md、两份索引；落地取号、状态改 Implemented。
