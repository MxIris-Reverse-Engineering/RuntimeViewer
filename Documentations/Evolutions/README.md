# Evolution 提案索引

- **项目类型**: App（macOS，AppKit）

面向终端用户的应用，提案的「影响」一节关注用户可见变化、可发现性、数据与配置兼容、
平台与最低版本、发布流程，**不涉及 ABI**。

提案格式与流程见全局 `CLAUDE.md` 的「Evolution 提案制」一节，用 `/evolution <描述>` 创建。

愿景在提案**之上**：一个愿景统领多个提案，提案头部用「所属愿景」回指。见 [`../Visions/`](../Visions/)。
